# 🌦️ Weather App

A simple and interactive Weather Application built using **HTML, CSS, and JavaScript** as part of my first-week internship project at **Skillme**.

This project marks my first step into web development projects and gave me an opportunity to gain practical, hands-on experience as a first-year student.

## 📌 About the Project

The Weather App is designed to provide weather-related information through a simple and user-friendly interface. While building this project, I explored frontend development and learned how HTML, CSS, and JavaScript work together to create a web application. I used fLexbox to design and a large box is visible with today's report in this project with 7 small forecast boxes in the bottom.... In simple words HTML=skeleton, CSS = skin ,JavaScript = brain!!

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript** – Functionality and interactivity
